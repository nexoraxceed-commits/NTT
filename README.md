# NTT

Task tracker project using Python, Supabase, Cloudflare Pages, Render, and Git.

## Project Structure

- `Backend/` contains the Python FastAPI service.
- `Frontend/Pages/` contains HTML pages.
- `Frontend/Js/` contains browser JavaScript.
- `Frontend/Css/` contains stylesheets.
- `Resources/` contains deployment and service property files.

## Deployment Paths

- Render backend root directory: `Backend`
- Cloudflare Pages build output directory: `Frontend`
